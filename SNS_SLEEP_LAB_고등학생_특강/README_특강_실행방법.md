# SNS × SLEEP LAB — 고등학생 빅데이터·스몰데이터 특강

**주제:** 우리 학교 1·2·3학년의 SNS 사용시간과 수면시간에는 어떤 관계가 있을까?

> **중요:** 이 자료의 학교와 학생은 실제 존재하지 않습니다. 1~3학년 각 300명, 총 900명의 **가상 익명 합성 데이터**를 만들었습니다. 실존 학생의 설문을 확보하거나 SNS 계정을 크롤링한 자료가 아닙니다. 예측 결과 역시 실제 건강 상태나 미래 행동의 진단·예언이 아닙니다.

### 크롤링 환경 설명

수업 당일 외부 사이트가 막혀도 작동하도록, 노트북이 만든 `sns_sleep_survey_source.html`을 **Colab 런타임 내부의 임시 HTTP 서버**에서 제공합니다. Python `requests.get()`은 HTTP GET 요청을 보내고, `BeautifulSoup`은 HTML의 `<table id="survey-table">`에서 각 행을 수집합니다. 단순히 CSV를 직접 읽는 단계로 크롤링을 대체한 것이 아니라, **HTTP 수집 + HTML 파싱**을 수행합니다. 단, 대상 사이트와 응답 자료는 실습용으로 생성한 가상 데이터입니다.

공개 GitHub Pages 등으로 `sns_sleep_survey_source.html`을 게시했다면 노트북 0번 환경 설정 셀의 `PUBLIC_CLASS_PAGE_URL`에 URL을 지정해 원격 HTTP 수집을 연습할 수 있습니다. 접근 실패 시 내부 HTTP 서버로 자동 전환합니다.

## 3. 실습 방식 B — 코딩 없이 HTML5 웹앱 사용하기

1. ZIP을 압축 해제하고 `02_웹앱/sns_sleep_nocode_webapp.html`을 Chrome 또는 Edge에서 엽니다. 서버·Python·계정이 필요하지 않습니다.
2. **웹페이지 데이터 수집 시연**을 누릅니다. 내장된 가상 설문 HTML을 브라우저 `DOMParser`로 읽어 912행을 추출합니다. 실제 외부 사이트 접속은 아닙니다.
3. **원본 CSV 저장**으로 다운로드합니다. **전처리 실행** 후 900행으로 줄어드는 모습을 확인합니다.
4. **900명 전체 / 30명 표본**을 눌러 상관계수를 비교합니다. **학년 필터**를 바꿉니다.
5. **AI에게 만약에 질문하기**에서 하루 SNS 180분, 매주 변화 +15분, 학년 2, 야간 사용 Y를 바꿔 예측값이 어떻게 바뀌는지 살펴봅니다.
6. **HTML 인포그래픽 다운로드**를 눌러 현재 설정의 차트·분석값이 들어간 독립 HTML을 저장합니다.
7. 자신의 **승인된 익명 CSV**를 불러와 같은 분석을 다시 실행할 수도 있습니다. `05_크롤링자료/sns_sleep_survey_source.html`을 `HTML 표 불러오기`로 가져올 수도 있습니다.

### 웹앱에서 URL 크롤링을 시험할 때 주의

웹브라우저는 CORS(교차 출처 리소스 공유) 정책으로 다른 도메인의 HTML 페이지 읽기를 차단할 수 있습니다. 웹앱의 `웹주소 가져오기` 기능은 **수신 웹서버가 CORS를 허용하는 경우에만** 성공합니다. 실패하면 기본 HTML 파싱 실습 또는 HTML 파일 업로드를 사용하세요. **코랩 `requests.get()` 크롤링에는 브라우저 CORS 제한이 적용되지 않습니다.**

### 내가 만든 CSV 형식

```csv
record_no,grade,sns_minutes,sleep_minutes,late_night_sns
R0001,1,286,517,Y
R0002,1,70,527,N
R0003,1,224,438,N
```

- `record_no`: 이름·학번이 아닌 익명 **행 번호**. 선택 사항이며 없으면 웹앱에서 생성합니다.
- `grade`: 숫자 1 / 2 / 3
- `sns_minutes`: 주중 하루 SNS 사용시간(분)
- `sleep_minutes`: 주중 1박 수면시간(분)
- `late_night_sns`: 밤 10시 이후 사용 Y 또는 N
- CSV 인코딩: UTF-8 권장(Excel에서는 UTF-8 BOM도 지원).

| 항목 | 가상 실습 결과 |

| 전체 상관계수 | 약 -0.363 |
| 가상 예측 | 2학년/야간 SNS Y, 하루 180분 기준, 4주간 SNS +15분/주 가정 시 모델 수면 추정값 약 13분 감소 |

참고: 전처리 기준(SNS 0–600분, 수면 180–720분, 7시간 구분)은 분석 교육을 위한 범위 설정이며 임상 진단기준이 아닙니다.

## 6. 지도 시 꼭 구분할 내용

- **스몰데이터**: 이 수업에서는 30행. 작은 자료의 질과 맥락을 파악하는 데 유용하지만 표본 변동이 큽니다.
- **상대적으로 큰 데이터**: 이 수업에서는 900행. 실제 산업 수준의 빅데이터가 아닙니다. 규모 차이를 관찰하는 교육용 비교입니다.
- **상관관계**: 다른 변수가 개입할 수 있습니다. 공부시간, 스트레스, 학원 귀가시간, 평일/주말 등이 함께 변할 수 있습니다.
- **예측**: 가상 시나리오에 회귀모형을 적용한 **조건부 추정**입니다. 단면 자료만으로 실제 시간 경과에 따른 미래를 확정할 수 없습니다.
- **데이터 보호**: 미성년자 설문을 할 때는 학교 방침과 적절한 동의를 확인하고 직접식별자를 수집하지 않으며, 응답자를 역추적할 수 있는 작은 집단의 통계도 주의합니다.
