# DEX//LAB — 고등학생 빅데이터·스몰데이터 × AI 특강

## 1. 실습 소개

**테마:** 포켓몬 도감의 HP, 공격, 방어, 특수공격, 특수방어를 분석하고, 가상의 신규 캐릭터에 부여할 스피드를 데이터로 추정하기.

5단계 흐름: **수집(HTML 크롤링) → 저장(CSV) → 처리(중복/결측/숫자 정제) → 분석(평균, 순위, 산점도) → 결과(인포그래픽 및 AI 예측)**.

### 제공 파일

| 파일 | 용도 |
|---|---|
| `DEX_LAB_Colab.ipynb` | Colab에서 바로 열어 `런타임 > 모두 실행`할 수 있는 완전 독립형 노트북 |
| `pokemon_data_lab.py` | 같은 데이터 파이프라인을 코드파일 하나로 실행하는 Python 스크립트 |
| `pokemon_data_lab_webapp.html` | **코딩 없는 HTML5 웹앱**. HTML 샘플 수집·CSV 다운로드·업로드·필터링·시각화·예측 |
| `pokemon_raw_sample.csv` | 원자료 시범 파일. **90행**, 메가 형태 등 중복 2행 포함 |
| `pokemon_sample.csv` | 정제한 시범 파일. **88행** |
| `pokemon_clean.csv` | 실제 Python 실습으로 생성한 정제 CSV의 **예비 샘플 기반 실행 예시** |
| `pokemon_small30.csv` | 샘플 데이터 중 30행 선택 결과 |
| `pokemon_report.html` | **예비 샘플을 이용해 생성한 오프라인 독립형 인포그래픽**. Plotly JS 포함 |

CSV 샘플은 공개 도감에서 확인한 스타터 포켓몬과 일부 유명 캐릭터를 선별한 교육용 **편의표본**입니다. 전체 포켓몬을 대표하는 확률표본이 아닙니다. **전체 도감 CSV는 Colab에서 온라인 크롤링에 성공할 경우 자동 생성**됩니다. 웹 차단, 네트워크 제한, 페이지 구조 변경으로 수집이 실패하는 경우 크롤링이 되었다고 표시하지 않고 내장 샘플을 사용합니다.

## 2. A 실습: 코딩하면서 데이터 수집/분석 — Google Colab

1. Chrome에서 <https://colab.research.google.com/> 을 엽니다. Google 계정으로 로그인합니다.
2. 상단 메뉴 `파일 → 노트 업로드`에서 `DEX_LAB_Colab.ipynb`를 선택합니다.
3. 상단의 `런타임 → 모두 실행`을 클릭합니다. 외부 파일이나 별도 API 키를 준비할 필요가 없습니다.
4. 첫 번째 수집 셀의 메시지를 읽습니다.
   - `실시간 웹 크롤링`: 도감 HTML 표를 requests/BeautifulSoup로 읽었습니다.
   - `수업용 검증 샘플 (실시간 수집 아님)`: 외부 접근에 실패하였으며 내장된 예비 자료로 이어서 실행합니다.
5. 각 셀에서 `df_raw`, `df_clean`, `df_small`, 그래프, AI 예측 결과를 비교합니다.
6. 가상 캐릭터 `NEW_MONSTER = {"HP":78, "공격":95, "방어":76, "특수공격":105, "특수방어":82}` 값을 직접 바꾸고 **6번 이후 셀**을 다시 실행합니다.
7. 마지막 셀에서 생성되는 `DEX_LAB_Colab_결과물.zip`을 다운로드합니다. 포함 파일: `pokemon_collected_raw.csv`, `pokemon_clean.csv`, `pokemon_small30.csv`, `pokemon_report.html`.
8. ZIP에 담긴 CSV를 브라우저 웹앱으로 다시 업로드해서, 코드 방식과 노코드 방식을 연결해 봅니다.

### .py 파일로 실행하고 싶다면

Colab의 왼쪽 `파일` 탭에서 `pokemon_data_lab.py`를 업로드하고 새 코드 셀에서 아래 한 줄을 실행합니다.

```python
!python pokemon_data_lab.py
```

스크립트는 현재 폴더에 CSV와 보고서 HTML, ZIP 파일을 저장합니다. **처음 배우는 학생에게는 `.ipynb` 방식**이 더 쉽습니다.

### 주요 기술

- 수집: `requests.get()`, `BeautifulSoup.select('table#pokedex tbody tr')`
- 저장: `DataFrame.to_csv(..., encoding='utf-8-sig')`
- 처리: `dropna`, `to_numeric`, `drop_duplicates`, 총합 검증
- 분석: `groupby`, 평균값, 스피드 순위, Plotly 막대/산점/꺾은선 그래프
- 예측: `StandardScaler + KNeighborsRegressor(k=5)`, MAE 계산 및 유사 캐릭터 표시
- 심화: 충분한 전체 자료 확보 시 세대별 평균 스피드의 선형 추세로 가상 10세대 추정. 실제 신규 출시 데이터가 아니라는 경고와 함께 표시합니다.

> 주의: Colab에는 위 라이브러리가 보통 기본 설치되어 있습니다. 실행 환경이 변경되어 패키지가 없다는 오류가 나오면 첫 셀 앞에 `!pip -q install requests beautifulsoup4 pandas numpy scikit-learn plotly`를 추가합니다.

## 3. B 실습: 코딩 없이 즉시 이용 — HTML5 웹앱

1. `pokemon_data_lab_webapp.html`을 다운로드해 더블클릭하여 Chrome 또는 Edge에서 엽니다. 인터넷이나 서버 없이 시작 가능합니다.
2. `① HTML 샘플 수집` 버튼을 누릅니다. 브라우저 내에 포함된 HTML 표의 `tr/td`를 **실제로 DOMParser로 읽는 방식**이며, 외부 서버 크롤링은 아닙니다.
3. `② 원본 CSV 저장` 버튼을 클릭하여 **90행**을 내려받습니다.
4. `③ 데이터 전처리` 버튼을 눌러 중복 번호 **2행**이 제거된 것을 확인합니다.
5. `④ 정제 CSV 저장`을 눌러 **88행** 자료를 내려받습니다.
6. `스몰 · 30행`과 `전체 · 88행`을 번갈아 누르고, 스피드 순위·평균값·산점도의 차이를 관찰합니다.
7. 타입 필터 또는 검색창에 `Pikachu`를 넣어 데이터를 찾아봅니다.
8. `AI에게 미래를 물어보다`에서 5개 슬라이더를 움직여 신규 캐릭터 스피드를 예상해 봅니다. `공격 특화 실험`과 `방어 특화 실험`의 차이도 확인합니다.
9. Colab에서 다운로드한 `pokemon_clean.csv`를 **상단의 `CSV 불러오기`**로 선택하면 업로드한 데이터로 모든 그래프와 예측이 갱신됩니다.
10. 상단 `발표 모드`를 누르면 교실 시연용으로 제목 크기가 커집니다. 브라우저의 F11 전체화면을 함께 사용할 수 있습니다.

**브라우저 보안 관련 참고:** 외부 출처의 HTML을 로컬 HTML5 파일에서 JavaScript `fetch`로 직접 요청하면 대부분 CORS 정책에 의해 차단됩니다. 따라서 노코드 웹앱에서는 **로컬 HTML 파싱과 CSV 분석**을 체험하고, 실시간 외부 웹사이트 수집은 **Colab Python**에서 수행하도록 정확히 구분했습니다. 사용자가 자체 서버를 운영하지 않아도 됩니다.

### GitHub Pages로 배포

`pokemon_data_lab_webapp.html`을 GitHub 저장소에 업로드하고 `index.html`로 이름을 바꿔 Pages에 배포하면 학생들이 URL만으로 접속해 실습할 수 있습니다. GitHub Pages에서 CSV 업로드/다운로드, 필터·그래프·예측 기능을 모두 브라우저 로컬에서 수행하며 CSV가 서버로 전송되지 않습니다.

## 5. 기술·윤리적으로 중요한 주의점

- **빅데이터 개념:** 전체 도감이 1천 행 수준이라면 실제 빅데이터 산업의 거대 규모와 동일한 개념은 아닙니다. 이 강의는 데이터 규모 차이에 대한 **상대 비교 실습**입니다.
- **표본 편향:** 내장 88행은 스타터 진화 계열 중심으로 의도적으로 구성된 비무작위 샘플입니다. 이 자료로 타입 간 절대적 우열을 판단하면 오류가 생길 수 있습니다.
- **크롤링:** <https://pokemondb.net/robots.txt>에 `/pokedex/all` 차단은 보이지 않으나, 사이트 운영 정책은 변할 수 있습니다. 페이지 1회 수집만 수행하고 대량 반복 요청을 하지 않습니다. `<robots.txt>`와 이용 조건을 확인해야 합니다.
- **데이터 무결성:** CSV의 여섯 능력치 합이 `총합`과 맞는 행만 정제 자료에 반영합니다. 메가폼 등 중복을 삭제하므로 분석 결과는 **기본 도감 번호 기준**입니다.
- **AI 예측:** KNN은 서로 비슷한 캐릭터를 비교한 **입문용 수치 추정**입니다. 향후 정식 캐릭터의 능력치를 예고하는 기능이 아닙니다. 평균절대오차가 크면 예측의 정확성이 낮습니다.
- **미래 세대 추세:** 선형 외삽에는 한계가 크므로 전체 도감으로 9세대가 충분히 확인된 경우에만 *학습용 시나리오*를 표시합니다. 샘플 파일에서는 이 예측을 숨깁니다.
